# IMAGE ENHANCER
Enhance low-resolution images to Full HD (1920×1080) while maintaining their aspect ratio. - **Simple Interface:** Clean design with drag-and-drop uploads, sharpness controls, and before-and-after comparison. - **Advanced Restoration:** Uses noise reduction, Lanczos-4 upscaling, CLAHE contrast enhancement, and image sharpening. - **Multiple Export Formats:** Download enhanced images in PNG, JPEG (95% quality), or WebP. - **Three Operating Modes:**   - Web-based interface.   - Desktop application using Tkinter (`--desktop`).   - Command-line support for single and batch processing.
